# Описание проекта "EstimateAI": Функционал и Структура

## 1. Видение и ключевая ценность

**EstimateAI** — это интеллектуальный помощник для инженеров-сметчиков и монтажников слаботочных систем. Наша платформа автоматизирует рутинную работу по созданию смет, превращая часы ручного труда в минуты, и предоставляет инструменты для точного ценообразования и профессионального управления проектами.

**Ключевая ценность:** Мы не просто распознаем текст. Мы понимаем контекст проекта, помогаем исправлять ошибки, управляем ценами и создаем профессиональные документы, освобождая время инженеров для решения более сложных задач и увеличивая их доход.

---

## 2. Ключевые функции и их преимущества

### 2.1. AI-Анализ проектной документации

*   **Что это:** Сердце системы. Пользователь загружает PDF-файл или изображение (проект, спецификацию, план), и ИИ автоматически извлекает полную спецификацию оборудования, материалов и работ.
*   **Особенности:**
    *   **Мультимодальность:** Работает с PDF-файлами, сканами и даже фотографиями.
    *   **Интеллектуальное распознавание:** ИИ не просто копирует текст, а определяет тип системы, название объекта и другие ключевые параметры проекта.
    *   **Автоматическое структурирование:** Данные сразу представляются в виде удобной таблицы, готовой к редактированию.
*   **Преимущества для пользователя:**
    *   ✅ **Экономия времени:** Сокращает время на создание сметы с нескольких часов до 2-5 минут.
    *   ✅ **Снижение ошибок:** Исключает человеческий фактор и ошибки при ручном переносе данных.
    *   ✅ **Начало работы за секунды:** Позволяет мгновенно получить основу для будущей сметы.

### 2.2. "Цикл Уточнения" — совместная работа с ИИ

*   **Что это:** Уникальный итеративный процесс, позволяющий пользователю "обучать" ИИ и исправлять его ошибки прямо в интерфейсе.
*   **Особенности:**
    *   **Разметка статусами:** Пользователь может пометить каждую строку как:
        *   🟢 **Утверждено:** "Замораживает" строку, защищая от дальнейших изменений ИИ.
        *   🔴 **Разделить:** Указывает ИИ, что в одной строке "склеены" несколько позиций.
        *   🔵 **Разобрать:** Указывает ИИ, что нужно извлечь модель/бренд из общего наименования.
        *   🟡 **Уточнить:** Отправляет строку на повторный, более глубокий анализ.
    *   **Кнопка "Уточнить по разметке":** Запускает повторный, сфокусированный анализ только проблемных строк.
*   **Преимущества для пользователя:**
    *   ✅ **Полный контроль:** Пользователь — "директор", а ИИ — "помощник". Конечный результат всегда под контролем человека.
    *   ✅ **Высочайшая точность:** Позволяет добиться 100% корректности спецификации, исправляя даже самые сложные ошибки ИИ.
    *   ✅ **Интерактивность:** Превращает монотонную вычитку в быстрый и удобный процесс.

### 2.3. Приватная База Цен и Авто-подбор (PRO-функция)

*   **Что это:** Инструмент для создания и управления собственной базой цен на работы и материалы.
*   **Особенности:**
    *   **Автоматическое пополнение:** Любой проект можно одним кликом добавить в базу цен.
    *   **Импорт/Экспорт в Excel:** Легко загрузить существующий прайс-лист или выгрузить базу для анализа.
    *   **Умный подбор цен:**
        *   **Для материалов:** Поиск по **точному совпадению модели/артикула** для максимальной точности.
        *   **Для работ:** Поиск по названию с высоким порогом схожести (85%).
    *   **Фильтрация по разделам:** При подборе цен можно указать, в каких разделах вашей базы искать совпадения (например, искать камеры только в "Видеонаблюдении").
*   **Преимущества для пользователя:**
    *   ✅ **Управление прибылью:** Позволяет использовать собственные, проверенные цены, а не рыночные.
    *   ✅ **Автоматизация ценообразования:** Экономит время на ручном заполнении цен.
    *   ✅ **Консистентность:** Гарантирует, что во всех сметах используются одинаковые цены на одинаковые позиции.

### 2.4. Управление проектами и историей

*   **Что это:** Единое пространство для всех расчетов пользователя.
*   **Особенности:**
    *   **История запросов:** Все обработанные файлы хранятся в виде проектов.
    *   **Черновики и версии:** Любую смету можно сохранить как черновик, создавать несколько версий одного проекта.
    *   **Группировка по объектам:** Проекты можно объединять в папки (объекты) для удобной навигации.
    *   **Архивация и удаление:** Ненужные проекты можно заархивировать или удалить.
    *   **Система тикетов:** Если пользователь считает, что ИИ допустил ошибку и с него списали кредиты зря, он может создать "жалобу", которая попадет на рассмотрение администратору.
*   **Преимущества для пользователя:**
    *   ✅ **Порядок в документах:** Все сметы и расчеты всегда под рукой.
    *   ✅ **Многоверсионность:** Легко возвращаться к старым проектам и создавать на их основе новые.
    *   ✅ **Справедливость:** Механизм жалоб повышает доверие к сервису.

### 2.5. Гибкая генерация коммерческих предложений

*   **Что это:** Инструмент для создания финальных документов для клиента.
*   **Особенности:**
    *   **Генерация PDF, DOCX, XLSX:** Создает профессионально выглядящие документы с реквизитами компании пользователя.
    *   **Настройка налогов:** Поддержка всех основных систем налогообложения (Без НДС, НДС в т.ч., НДС сверху, УСН).
    *   **Дополнительные услуги:** Легко добавить в смету ПНР, выезды, стоимость исполнительной документации и другие работы.
*   **Преимущества для пользователя:**
    *   ✅ **Профессиональный имидж:** Позволяет за несколько кликов создавать документы, которые не стыдно отправить клиенту.
    *   ✅ **Гибкость:** Адаптируется под любую схему работы и налогообложения.
    *   ✅ **Экономия времени:** Автоматизирует создание и форматирование документов.

### 2.6. Управление контрагентами

*   **Что это:** Адресная книга для хранения реквизитов своих компаний или ИП.
*   **Особенности:**
    *   Поддержка ООО, ИП, Самозанятых.
    *   Автозаполнение реквизитов по ИНН через интеграцию с DaData.
    *   Возможность установить одну компанию "по умолчанию" для быстрой генерации КП.
*   **Преимущества для пользователя:**
    *   ✅ **Все под рукой:** Не нужно каждый раз искать и копировать реквизиты.
    *   ✅ **Ускорение работы:** Выбор компании из списка при генерации КП занимает секунду.

### 2.7. Партнерская программа

*   **Что это:** Система вознаграждения для пользователей, привлекающих новых клиентов.
*   **Особенности:**
    *   **Многоуровневая система:** Статусы "Бронза", "Серебро", "Золото", "Платина" с растущим процентом вознаграждения.
    *   **Несколько источников дохода:** 100% с первого платежа, % с последующих, доход с интеграций, доход со второго уровня партнеров.
    *   **Кабинет партнера:** Статистика по рефералам, заработанным средствам, маркетинговые материалы.
*   **Преимущества для пользователя:**
    *   ✅ **Дополнительный доход:** Возможность зарабатывать, рекомендуя сервис.
    *   ✅ **Карьерный рост:** Прозрачная система роста от новичка до эксклюзивного представителя.

## 3. Структура сайта

1.  **/ (Посадочная страница / Лендинг)** - **Цель: Продажа и информирование.**
    *   Главный экран с УТП (Уникальным Торговым Предложением).
    *   Блок "Как это работает".
    *   Детальное описание ключевых функций.
    *   Тарифы и таблица сравнения функций.
    *   Калькулятор дохода для партнеров.
    *   FAQ.
    *   Кнопки "Попробовать бесплатно" (открывает модальное окно регистрации) и "Войти".

2.  **/partnership** - **Цель: Привлечение партнеров.**
    *   Лендинг, посвященный партнерской программе, с калькулятором дохода и формой заявки.

3.  **/auth/login** - **Цель: Вход в систему.**
    *   Форма входа по Email/Паролю.

4.  **/auth/register** - **Цель: Регистрация нового пользователя.**
    *   Отдельная страница регистрации (для ссылок из формы входа).

5.  **/dashboard** - **Цель: Главный рабочий стол.**
    *   Основной интерфейс для загрузки нового файла для анализа.
    *   История проектов с поиском и группировкой.

6.  **/dashboard/calculator** - **Цель: Редактирование и работа со сметой.**
    *   Таблица со спецификацией, полученной от ИИ.
    *   Инструменты "Цикла Уточнения".
    *   Калькулятор стоимости работ (СМР).
    *   Настройки КП (налоги, доп. услуги).
    *   Итоговая таблица расчета.
    *   Кнопки для сохранения и генерации документов.

7.  **/dashboard/profile** - **Цель: Настройки пользователя.**
    *   Табы: Профиль, Баланс, Мои тикеты, Мои компании.
    *   Редактирование данных профиля, интеграция с Telegram.

8.  **/dashboard/bonus** - **Цель: Кабинет партнера.**
    *   Статистика по рефералам, баланс, маркетинговые материалы.
    *   Отображение партнерского соглашения для новых партнеров.

9.  **/dashboard/admin/** - **Цель: Управление системой.** (Только для Super Admin)
    *   Дашборд с основной аналитикой.
    *   Управление пользователями, их ролями и балансом.
    *   Рассмотрение тикетов.
    *   Редактирование AI-промптов и настроек.

10. **/legal/** - **Цель: Юридическая информация.**
    *   `/privacy-policy`, `/license`, `/consent`.
